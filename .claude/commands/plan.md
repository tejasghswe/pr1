# Plan

Inspect the repository and produce an implementation plan.

Do not modify code.

Return:

## Problem Understanding
Restate the task and identify the expected behavior.

## Repository Findings
List the relevant files, modules, interfaces, tests, and existing patterns.

## Proposed Design
Describe the smallest reasonable implementation.

## Edge Cases
List important boundary, invalid-input, failure, and scale cases.

## Test Strategy
Describe targeted tests and broader validation.

## Assumptions / Questions
List assumptions. Ask only questions that materially affect the implementation.
