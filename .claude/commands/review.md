# Review

Review the current working tree / git diff as a senior engineer.

Do not modify files.

Check for:

1. Correctness bugs
2. Missing edge cases
3. Incorrect assumptions
4. Error-handling problems
5. Complexity or scalability concerns
6. Security concerns
7. Unnecessary changes
8. Naming/readability problems
9. Missing or weak tests

Rank findings:

- P0: critical/blocking
- P1: important
- P2: non-blocking

For each finding include:
- Severity
- File/area
- Problem
- Why it matters
- Suggested fix

If there are no findings, say so explicitly and mention remaining test/validation gaps, if any.
